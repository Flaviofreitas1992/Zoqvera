# Zoqvera

Site institucional da **Zoqvera**, empresa de desenvolvimento de sites, landing pages, softwares, plataformas digitais e soluções de inteligência artificial.

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — navegação mobile, efeitos de entrada e comportamento do formulário
- `assets/favicon.svg` — favicon da marca

## Direção de design

A interface usa uma estética tecnológica premium com fundo grafite, alto contraste, verde elétrico como cor de assinatura e azul como cor secundária. O layout foi pensado para destacar capacidades, projetos e processo de trabalho sem depender de imagens genéricas de banco de imagens.

Os projetos podem ser substituídos ou ampliados conforme o portfólio da empresa evoluir.

## Publicação

O projeto é estático e pode ser publicado diretamente em serviços como Cloudflare Pages ou GitHub Pages, sem etapa de build.

### Cloudflare Pages

- Framework preset: `None`
- Build command: deixar vazio
- Build output directory: `/`

## Próximas configurações recomendadas

- Conectar o formulário de contato a um e-mail, WhatsApp ou endpoint próprio.
- Definir domínio oficial da Zoqvera.
- Adicionar imagem Open Graph própria para compartilhamento.
- Confirmar quais projetos devem permanecer no portfólio público.
- Adicionar analytics e Search Console quando o domínio estiver publicado.
